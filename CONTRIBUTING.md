# Contributing

Thanks for helping improve FastAPI Supabase Starter.

The source code lives in a private repository that license holders are invited to after purchase. This public repository holds the README, license and policies, so anyone can report a problem or ask for a feature here.

## Report a bug

Open an issue with:

- what you did, what you expected and what happened
- versions: Python, Node, and hosted Supabase or the Supabase CLI
- logs or screenshots, with keys and tokens removed

License holders can also open issues in the private repository.

## Ask for a feature

Open an issue that describes the problem you want solved. The "Coming next" section of the [README](README.md#coming-next) lists what's planned; a 👍 on an existing issue helps us decide what comes first.

## Pull requests

- **This repository:** fixes to the README and other docs are welcome.
- **Code:** license holders open pull requests in the private repository. By submitting a contribution you agree it may be included in the starter and distributed under its [license](LICENSE).

## Security issues

Don't open a public issue. Follow [SECURITY.md](SECURITY.md).
