# Security policy

Please report vulnerabilities privately, never in a public issue.

Email [budemadeofficial@gmail.com](mailto:budemadeofficial@gmail.com) with "Security" in the subject and include:

- what is affected (file, endpoint, migration or page)
- steps to reproduce
- the impact you see

We'll acknowledge your report, keep you updated while we work on it, and credit you in the release notes if you'd like. Fixes ship through the private repository that license holders are invited to.

Only the latest release is supported.
